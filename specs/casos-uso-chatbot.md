# Casos de uso - Chatbot de recomendaciones

## Casos
- "Recomendame una novela corta de misterio"
- "¿Qué película puedo ver según mis gustos?"
- "Quiero escuchar algo parecido a este álbum"
- "Recomendame un paper relacionado con inteligencia artificial"

## Criterios
Usar: gustos, historial, calificaciones, guardados/completados, categorías/autores seguidos, información del MCP interno.
No usar RAG inicialmente - evaluar después.
